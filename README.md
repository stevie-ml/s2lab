# S₂ Lab

Information-theoretic analysis of poetry. `engine.py` computes token-level surprisal, entropy, and S₂ for texts using GPT-2 (English and German models), saving structured per-token results for downstream analysis.

`findings/` contains experiment reports: meter and enjambment vs. S₂, repetition and entropy, metaphor detection, cross-model comparisons, and per-poet "S₂ fingerprints."
