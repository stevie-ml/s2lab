# S₂ Lab

Information-theoretic analysis of poetry. `engine.py` computes token-level surprisal, entropy, and S₂ for texts using GPT-2 (English and German models), saving structured per-token results for downstream analysis.

`findings/` contains experiment reports: meter and enjambment vs. S₂, repetition and entropy, metaphor detection, cross-model comparisons, and per-poet "S₂ fingerprints."

## ⚠️ Known confound: read this before using any S₂ number

`findings/stanza_break_artifact.md` (2026-09-21) documents a layout artifact that inflates a large share of this lab's published results. At positions where GPT-2 assigns ≥90% probability to a newline continuation — 31.5% of line heads, 4.5% of all tokens — entropy collapses to ~0 and S₂ reduces to surprisal, so *any* non-newline token scores ~20 bits regardless of the poet's choice. These positions measure the model's confidence in the poem's **typographic layout**, not poetic deviation.

Affected: line-head/enjambment results (the effect vanishes entirely: +6.30 → −0.10), all era rankings (haiku 1st → 12th, ballad 4th → 15th), and all top-poem rankings (*The Red Wheelbarrow* 3.59 → −0.14). Contamination tracks poem layout — short-lined, heavily stanza'd forms are most exposed.

The project's core claim survives: the poetry–prose gap retains 72% of its magnitude (+1.849 → +1.333 bits) and is not artifact-driven. But poetry's absolute avg S₂ is **negative** (−0.388) once cleaned, not positive as reported.

Filter with `p(newline) ≥ 0.9` before interpreting any S₂ statistic. Reports generated by `researcher.py` do not yet apply this filter.
